Approach

Research first

I start with merchants: usability sessions, client interviews and support tickets, before I draw a screen.

Accessible by default

Everything is designed to WCAG 2.1 AA, with contrast, keyboard order and clear errors built into each component.

Systems thinking

Every redesigned screen feeds a shared component library, so the next one is faster and more consistent.

Built with developers

Specs, build reviews and early feasibility checks so what ships matches what I designed.
